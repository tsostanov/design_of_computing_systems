# Проектирование вычислительных систем

Лабораторные работы по дисциплине «Проектирование вычислительных систем». Вариант 3.

## Лабораторная работа №1 — GPIO. «Азбука Морзе»

**Условие:** реализовать передатчик азбуки Морзе на стенде SDK-1.1М:

- Запоминать последовательность до 8 нажатий кнопки: короткое — точка, длинное — тире.
- После каждого введённого символа кратко включать двухцветный светодиод: жёлтый для точки, красный для тире.
- После долгой паузы воспроизводить последовательность один раз зелёным светодиодом: короткими и длинными импульсами.
- После передачи возвращаться к вводу новой последовательности.

Реализованы неблокирующие драйверы кнопки и светодиодов, программный антидребезг и собственный драйвер GPIO с прямым доступом к регистрам. Время отсчитывается через SysTick; дополнительные таймеры и прерывания GPIO не используются.

**Платформа:** STM32F427VIT6, STM32CubeIDE 1.9.0. Для сборки импортировать корневую папку как существующий проект STM32CubeIDE и выполнить Build Project.
